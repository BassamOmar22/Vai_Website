# VAI four-category design comparison matrix
Status: proposals for evaluation unless explicitly described as historical/reported. None of the new concepts was implemented or runtime-verified in this chat. Cost ratings are estimates pending measurement. A 2.5D CSS treatment is simulated depth, not evidence of a WebGL engine.

| Component / objective | Static 2D | 2D motion | Static 3D | 3D motion | Cost estimate / mobile / fallback | Decision / implementation status |
| --- | --- | --- | --- | --- | --- | --- |
| Home hero: communicate structured intelligence without new claims | Current labeled operating model, clearer typography and frames | One signal trace along supported paths/frame; stationary labels | Same composition as a pre-rendered shallow architectural object; no asset currently supplied | Same layers with a short controlled separation and rest; isolated comparison only | 2D low; real 3D medium/high and unverified. Mobile remains a readable static/2D model | Recommend 2D motion baseline; 3D alternatives experimental proposals |
| Architecture & Governance: make existing relationships legible | Exact current layers and labels, clearer grouping | Highlight existing layer as its existing explanation enters view; optional focus/tap emphasis | Spatial layer illustration only where depth clarifies existing grouping | Bounded layer separation, fixed camera, no navigation through space | 2D low/medium; WebGL unmeasured. All labels outside canvas; flattened mobile fallback | Highest-value spatial R&D candidate; approval pending |
| Method / workflow: show existing ordered progression | Existing steps and all descriptions in reading order | Finite rail trace; passive active-step accent; no hidden text | Not recommended without evidence of communication benefit | Not recommended for this pass | Low with CSS/SVG; mobile vertical rail; full static ordered content | Recommend 2D enhancement after audit |
| Industry cards: preserve equal importance and route discovery | Balanced grid, all five sectors visible | Link/focus response and restrained border/arrow motion | Not investigated; insufficient benefit | Not recommended | Low; no hover-only access or first-tap interception | Recommend minimal 2D feedback |

| Section boundaries: add continuity within existing order | Rules, tone changes, deliberate spacing | Decorative edge/field transition contained within section | Not investigated | Not applicable | Low if transform/opacity; no curtain over text; static mobile | Recommend restraint; no page-wide spectacle |

| Contact and confirmation: make real states clear | Existing form, real confirmation states | Focus feedback, legitimate loading indicator, short state transition | Not applicable | Not applicable | Low; preserve validation, consent, persistence and state logic | Minimal visual-only changes |
| Privacy / Terms / Footer: reading and navigation | Readable narrow text, contrast, complete footer | Ordinary focus/link feedback only | Not applicable | Not applicable | Low; no motion required | Keep static |
